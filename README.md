## Bookstore Management System (Multi-Agent)

An intelligent web-based bookstore management system that leverages multi-agent architecture and ontology-based knowledge modeling to simulate and automate bookstore operations efficiently.

🚀 Overview

This project integrates Artificial Intelligence concepts with a full-stack web application to create a smart system where multiple agents collaborate to manage tasks such as inventory handling, decision-making, and system monitoring.

✨ Features

🤖 Multi-Agent System for task coordination

🧠 Ontology-based knowledge representation using Owlready2

🌐 Web-based dashboard for monitoring system activities

📦 Bookstore operations simulation (inventory, updates, etc.)

⚡ Real-time interaction between system components

🛠️ Tech Stack
Layer	Technology
Backend	Python (Flask)
Frontend	HTML, CSS, JavaScript
AI Component	Owlready2 (Ontology)
Tools	Git, GitHub

⚙️ Installation & Setup
1. Clone the repository
git clone https://github.com/your-username/bookstore-management-system.git
2. Navigate to project folder
cd bookstore-management-system
3. Create virtual environment
python -m venv venv
source venv/bin/activate   # (Linux/Mac)
venv\Scripts\activate      # (Windows)
4. Install dependencies
pip install -r requirements.txt
5. Run the application
python run.py
